## 🏁 Sobre o projeto

> **Wolfer Auto Classics Reparos** é um projeto de conclusão de curso que retrata uma oficina mecânica fictícia especializada em carros antigos.

O projeto foi desenvolvido com uma identidade visual inspirada em **oficinas clássicas e no universo dos automóveis antigos**, buscando combinar uma apresentação profissional com elementos visuais relacionados à restauração e manutenção de veículos.

## 🚘 Identidade visual

A proposta visual do projeto foi inspirada no estilo de **carros clássicos e oficinas mecânicas tradicionais**, utilizando uma estética predominantemente sóbria e automotiva.

A apresentação procura transmitir a ideia de uma oficina especializada em veículos antigos, mantendo uma combinação de elementos clássicos com recursos de desenvolvimento web.
